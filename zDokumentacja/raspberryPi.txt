Uruchamianie usługi na Raspberry

1. Copy:
   powerguard-edge.jar
   run-edge.sh

   to:
   /home/powerguard/PG

2. Permissions:

   sudo chown -R powerguard:powerguard /home/powerguard/PG/powerguard-edge
   chmod +x /home/powerguard/PG/powerguard-edge/run-edge.sh

3. Create systemd service:

   sudo nano /etc/systemd/system/powerguard-edge.service

4. Paste the service definition.

[Unit]
Description=PowerGuard Edge
Wants=network-online.target
After=network-online.target

StartLimitIntervalSec=60
StartLimitBurst=5

[Service]
ExecStart=/home/powerguard/PG/powerguard-edge/run-edge.sh
WorkingDirectory=/home/powerguard/PG/powerguard-edge

StandardOutput=journal
StandardError=journal

Restart=on-failure
RestartSec=5s

User=powerguard

[Install]
WantedBy=multi-user.target



5. Reload and start:

   sudo systemctl daemon-reload
   sudo systemctl enable powerguard-edge.service
   sudo systemctl start powerguard-edge.service

6. Check:

   sudo systemctl status powerguard-edge.service --no-pager -l

7. Logs:

   journalctl -u powerguard-edge.service -f



Show only Java PIDs (process IDs)
pgrep -a java

*** Uruchamianie dockera na raspberry ***


#1. Check your raspberry
cat /etc/os-release
dpkg --print-architecture

#Ma być arm64 and Raspberry Pi OS based on Debian Bookworm or Trixie. Jeżeli tak nie jest, nie instalować dalej!

#1a. Check existing instalations (muszą być puste)
which docker
which podman
snap list 2>/dev/null


#2. Install prerequisites
sudo apt update
sudo apt install -y ca-certificates curl


#3. Add Docker's official signing key:
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc


#4. Add the repository:
sudo tee /etc/apt/sources.list.d/docker.sources > /dev/null <<EOF
Types: deb
URIs: https://download.docker.com/linux/debian
Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF


#5. Install Docker Engine and Compose:
sudo apt update

sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin



#6. Start Docker automatically
sudo systemctl enable --now docker


#7. Verify:
sudo systemctl status docker


#8. Test Docker:
sudo docker run hello-world


#9. Use Docker without sudo
sudo usermod -aG docker $USER

#10. check:
docker version
docker compose version
docker ps

*** Instalacja wewnętrznego nginx wewnątrz angulara ***
1. 
Zrobić backup
docker cp powerguard-frtnd_container_arm64:/etc/nginx/conf.d/default.conf ~/powerguard-nginx-default.conf.bak

2.
Utworzyć nową konfigurację
(This preserves your existing Angular configuration and adds backend routing.)
---
cat > ~/powerguard-nginx-default.conf <<'EOF'
server {
    listen 80;
    server_name _;

    root /usr/share/nginx/html;
    index index.html;

    # Runtime Angular configuration
    location = /env.js {
        add_header Cache-Control "no-store, no-cache, must-revalidate, proxy-revalidate, max-age=0";
        try_files $uri =404;
    }

    # PowerGuard REST API and WebSocket
    location /powerguard-bcknd/ {
        proxy_pass http://powerguard-bcknd_container_arm64:8080;

        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_read_timeout 3600s;
    }

    # Angular SPA — preserve page refresh functionality
    location / {
        try_files $uri $uri/ /index.html;
    }
}
EOF

===

3.
Copy it into the frontend container
docker cp ~/powerguard-nginx-default.conf powerguard-frtnd_container_arm64:/etc/nginx/conf.d/default.conf

4.
Validate Nginx
docker exec powerguard-frtnd_container_arm64 nginx -t

5.
Reload Nginx
docker exec powerguard-frtnd_container_arm64 nginx -s reload

6.Test the WebSocket connection
curl -i --http1.1 --max-time 5 \
  -H "Upgrade: websocket" \
  -H "Connection: Upgrade" \
  -H "Sec-WebSocket-Version: 13" \
  -H "Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==" \
  http://localhost/powerguard-bcknd/ws/measurements



*** make the Nginx configuration permanent

7.
Copy the working configuration to your Windows computer
na laptopie (Win11) w Powershell:
scp powerguard@powerguard.local:/home/powerguard/powerguard-nginx-default.conf "$env:USERPROFILE\Downloads\default.conf"
